# 丙級會計練習站

丙級會計事務學科練習網站。純靜態網頁（HTML／CSS／JavaScript，無任何外部相依），可直接部署到 GitHub Pages。

## 功能

| 功能 | 說明 |
|---|---|
| 題庫練習 | 186 題（單選 156、複選 30），涵蓋 12 個單元。可依單元、題型、範圍（全部／未作答／曾答錯／已收藏）、順序與題數篩選，作答後立即顯示正解與解析 |
| 模擬考 | 單選 60 題（每題 1 分）＋複選 20 題（每題 2 分，全對才給分），限時 100 分鐘，60 分及格。有題號導覽、標記待檢查，時間到自動交卷；中途離開不會遺失進度 |
| 錯題本 | 練習與模擬考答錯的題目自動收錄，可依單元篩選後集中重練；連續答對 N 次（可設定）自動移出 |
| 成績分析 | 模擬考分數走勢圖、各單元正答率、弱點單元建議、歷次模擬考紀錄 |
| 響應式介面 | 手機版使用底部導覽列，支援淺色／深色模式；電腦版支援鍵盤快捷鍵（1–4 選答、Enter 下一題、← → 切換題目） |
| 資料備份 | 作答紀錄存在瀏覽器 localStorage，可匯出／匯入 JSON 備份 |

## 單元

會計基本概念、會計循環與分錄、調整與結帳、現金與內部控制、應收款項與票據、存貨、不動產廠房及設備、負債與權益、財務報表、商業會計法、營業稅與所得稅、共同科目（職業安全衛生、工作倫理、環境保護、節能減碳）。

## 專案結構

```
index.html                     頁面骨架
css/style.css                  樣式（含深色模式、手機版）
js/questions.js                題庫資料
js/app.js                      應用程式邏輯（路由、練習、模擬考、錯題本、分析）
assets/icon.svg                網站圖示
manifest.webmanifest           加入手機主畫面設定
scripts/validate-questions.js  題庫結構檢查
.github/workflows/pages.yml    GitHub Pages 自動部署
```

## 本機預覽

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

直接雙擊 `index.html` 也能使用。

## 部署到 GitHub Pages

1. 將程式碼合併到 `main` 分支。
2. 到 Repository 的 **Settings → Pages**，**Source** 選擇 **GitHub Actions**。
3. 每次推送到 `main` 時，工作流程會先檢查題庫，再自動部署；也可在 **Actions** 頁面手動執行 *Deploy to GitHub Pages*。

網址會是 `https://<帳號>.github.io/<repository 名稱>/`。

## 新增題目

在 `js/questions.js` 對應區塊的**末端**加入：

```js
Q('tax', '題目文字', ['選項A', '選項B', '選項C', '選項D'], 1, '解析');            // 單選：答案為索引（0 起算）
Q('tax', '題目文字（複選）', ['選項A', '選項B', '選項C', '選項D'], [0, 2], '解析'); // 複選：答案為索引陣列
```

題目編號依各分類出現順序自動產生，作答紀錄與錯題本都以編號對應，所以**請只在末端新增、不要插入或刪除既有題目**。新增後執行：

```bash
node scripts/validate-questions.js
```
